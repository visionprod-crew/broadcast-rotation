# 3시예배 방송팀 로테이션 관리

구글 시트(월별 포지션 → 주간 공지용 시트 → 캡처 → 카톡 공지)로 하던 작업을 웹앱 하나로 옮긴 프로그램입니다.

| 기존 시트 | 웹앱 |
|---|---|
| 월별 포지션 시트에 이름 타이핑 | **월별 로테이션** 탭에서 이름을 **선택** (가능 포지션 추천, 중복·불참 자동 경고) |
| 주간 공지용 시트에 복사 → 캡처 | **주간 공지** 탭에서 카드 이미지 자동 생성 → **카카오톡으로 공유** |
| 명단 시트 | **팀원** 탭 (이름·또래·연락처·비고·가능 포지션·활동 여부) |
| — | 메인 관리자 / 팀장 / 부팀장 **계정**과 권한 |

2026.01~11 시트 데이터(로테이션 47회, 명단)가 미리 들어 있습니다.

---

## 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소 만들기 (예: `broadcast-rotation`)
2. 이 폴더의 파일을 그대로 업로드: `index.html`, `app.js`, `config.js`, `seed.js`, `firestore.rules`, `README.md`
   - ⚠️ `vfc-rotation-backup.json`(연락처 포함)은 **올리지 마세요.** 공개 저장소면 누구나 볼 수 있습니다.
3. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/broadcast-rotation/` 접속
5. 아이폰 사파리: 공유 버튼 → **홈 화면에 추가** 하면 앱처럼 쓸 수 있어요.

## 2. 처음 실행 (로컬 모드)

`config.js`의 `firebase`가 `null`이면 **로컬 모드**입니다. 데이터와 계정이 그 기기 브라우저에만 저장돼요.

1. 첫 화면에서 **메인 관리자 계정** 만들기 (아이디 기본값 `admin`)
2. 설정 → **백업 파일 가져오기** → `vfc-rotation-backup.json` 선택 → 연락처까지 포함된 명단이 들어갑니다.
3. 설정 → **팀장·부팀장 계정 만들기**

> 로컬 모드의 계정은 같은 기기에서 여러 사람이 번갈아 쓸 때만 의미가 있어요.
> 팀장·부팀장이 **각자 폰**에서 로그인하려면 아래 Firebase 연결을 해주세요.

## 3. Firebase 연결 (계정 공유 + 실시간 동기화, 무료)

1. https://console.firebase.google.com → **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. **Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호 사용 설정**
3. **Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, 프로덕션 모드)
4. Firestore → **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**
   - `config.js`의 `ownerId`를 바꿨다면 규칙의 `admin@vfc-rotation.app`도 `<ownerId>@vfc-rotation.app`로 바꿔주세요.
5. **프로젝트 설정(톱니) → 내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값을 `config.js`의 `firebase:` 에 붙여넣기
6. Authentication → **설정 → 승인된 도메인**에 `<아이디>.github.io` 추가
7. GitHub에 `config.js` 다시 올리기 → 사이트 접속
8. **처음 설정: 메인 관리자 계정 만들기** 버튼으로 `admin` 계정 생성 (⚠️ 연결 직후 바로 만들어 두세요)
9. 설정 → **백업 파일 가져오기**로 `vfc-rotation-backup.json` 업로드 → 모든 기기에 공유됨
10. 설정 → **팀장·부팀장 계정 만들기** → 아이디/비밀번호를 당사자에게 전달

> `config.js`의 Firebase 값은 공개돼도 괜찮은 값입니다. 데이터 보호는 4번의 보안 규칙이 담당하며,
> 로그인한 팀장·부팀장·관리자만 명단과 로테이션을 읽고 쓸 수 있습니다.

## 권한

| | 메인 관리자 | 팀장 | 부팀장 |
|---|:-:|:-:|:-:|
| 로테이션 보기·편집, 공지 이미지 공유 | ✓ | ✓ | ✓ |
| 팀원 정보 보기 | ✓ | ✓ | ✓ |
| 팀원 추가·수정 | ✓ | ✓ | |
| 계정 만들기·삭제, 공지 문구, 백업 가져오기 | ✓ | | |

- Firebase 모드에서 비밀번호를 잊은 팀장·부팀장은 관리자가 계정을 삭제 후 새 아이디로 다시 만들어 주세요.
- 메인 관리자 비밀번호 분실 시: Firebase 콘솔 → Authentication에서 `admin@vfc-rotation.app` 사용자를 삭제 후 다시 생성.

## 카카오톡 공유

- **휴대폰**: 주간 공지 → `카카오톡으로 공유` → 공유 시트에서 카카오톡 → 방 선택
- **PC**: `이미지 복사` → 카톡 PC 대화창에 `Ctrl/⌘ + V`
- `텍스트로 복사`는 이미지 대신 글로 공지할 때 사용
- `이 달 전체`를 누르면 한 달치 카드를 한 장으로 만들어요 (기존 주간 공지용 시트 오른쪽 모양)

## 파일 구성

```
index.html        화면·스타일
app.js            기능 전체 (로컬/Firebase 저장소, 편집, 이미지 생성)
config.js         Firebase 연결·관리자 아이디 설정
seed.js           초기 데이터 (연락처 제외)
firestore.rules   Firebase 보안 규칙
```
